# Security Policy

## Reporting a vulnerability

Please do not publish security-sensitive details in a public issue.

For a responsible disclosure, contact the repository owner through the contact method published on the website and provide:

- affected URL or file
- reproducible steps
- impact
- minimal proof of concept, if safe

Do not include passwords, API keys, tokens, private keys, personal data, or other secrets in reports.

## Scope

This policy covers the website source, CI workflows, and publicly deployed website behavior.
