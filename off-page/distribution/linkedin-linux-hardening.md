## Hook

A Linux server can be “hardened” today and quietly drift tomorrow.

Packages change. Services get enabled. SSH policy gets modified. Firewall rules accumulate. Someone fixes an incident and forgets to document the change.

The practical question is not only:

> Did we harden the server?

It is:

> Can we detect when the approved hardening baseline changes?

I wrote a practical checklist covering SSH, accounts, patching, listening services, firewall policy, logging and recovery.
