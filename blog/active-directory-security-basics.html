SECURITY / ACTIVE DIRECTORY

اصول امنیت Active Directory؛ از حداقل دسترسی تا پایش

AD فقط یک سرویس Login نیست؛ بخش مهمی از سطح اعتماد شبکه است و باید مثل یک زیرساخت حساس محافظت شود.

۱. حساب‌های مدیریتی را محدود کن

حساب روزمره کاربر نباید برای مدیریت Domain استفاده شود. دسترسی مدیریتی را به حساب‌های جداگانه و نقش‌های مشخص محدود کن و عضویت گروه‌های privileged را مرتب بازبینی کن.

۲. اصل Least Privilege

هر کاربر و سرویس باید فقط مجوزی را داشته باشد که واقعاً برای انجام وظیفه نیاز دارد. مجوزهای قدیمی یکی از ساده‌ترین راه‌های گسترش اثر یک حساب compromise شده هستند.

۳. Group Policy را استاندارد کن

سیاست‌های Password، Lockout، Audit، Defender و تنظیمات امنیتی Endpoint را به‌صورت مستند و قابل بازبینی مدیریت کن. GPOهای زیاد و بدون مالکیت مشخص، مدیریت را سخت می‌کنند.

۴. سرویس‌های غیرضروری را حذف یا محدود کن

هر سرویس یا پروتکل اضافی سطح حمله را بیشتر می‌کند. قبل از تغییر، وابستگی سرویس‌ها را بررسی و نتیجه را مستند کن؛ Hardening بدون شناخت dependency می‌تواند خودش باعث قطعی شود.

۵. لاگ و Audit را جدی بگیر

ثبت رویدادهای احراز هویت، تغییرات گروه‌های حساس، ایجاد حساب و رخدادهای مهم باید قابل بررسی باشد. هدف فقط جمع‌کردن Log نیست؛ باید برای رخدادهای مهم دید و زمان نگهداری مشخص داشته باشی.

۶. Backup و Recovery

پشتیبان‌گیری زمانی ارزش دارد که بازیابی آن آزمایش شده باشد. سناریوی خرابی DC، حذف اشتباهی و compromise را جداگانه در برنامه Recovery در نظر بگیر.
