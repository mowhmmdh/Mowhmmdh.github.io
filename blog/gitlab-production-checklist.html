چک‌لیست GitLab Production

در GitLab فقط بالا آمدن سرویس کافی نیست؛ Availability، Data Protection و Recovery باید قابل اثبات باشند.

Production checklist: TLS → Storage → Backup → Restore Test → Runner Isolation → Secrets → Monitoring → Change/Rollback

TLS و دسترسی

  • HTTPS معتبر و redirect امن.
  • عدم انتشار سرویس‌های مدیریتی غیرضروری.
  • تفکیک دسترسی کاربران و مدیران.

Storage

فضای دیسک، رشد repository و artifactها را پایش کنید و برای exhaustion هشدار داشته باشید.

Backup و Restore

Backup بدون Restore Test یک فرض است. دوره‌ای بازیابی را در محیط کنترل‌شده آزمایش و زمان و نتیجه را ثبت کنید.

Runner و Secrets

Runnerها را بر اساس سطح اعتماد جدا کنید و secrets را در repository یا log قرار ندهید.

Change Management

هر تغییر مهم باید baseline، هدف، ریسک، validation و rollback داشته باشد.
