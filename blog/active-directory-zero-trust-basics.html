اصول Zero Trust در Active Directory

Zero Trust به معنی بی‌اعتمادی مطلق یا حذف Domain نیست؛ یک رویکرد برای این است که هر دسترسی بر اساس هویت، زمینه، حداقل سطح دسترسی و کنترل مستمر ارزیابی شود.

Principles: Verify Explicitly → Least Privilege → Separate Administration → Monitor → Reassess

حساب‌های مدیریتی را جدا کنید

استفاده روزمره از حسابی که مجوزهای Domain Admin دارد ریسک را بالا می‌برد. نقش‌های مدیریتی باید محدود، قابل ردیابی و تا حد امکان جدا از فعالیت‌های روزمره باشند.

سطح دسترسی را کاهش دهید

عضویت گروه‌ها، Delegation و مجوزهای Share و NTFS را دوره‌ای بررسی کنید. دسترسی‌ای که دیگر کاربرد ندارد باید حذف شود.

سیستم‌های حساس را تفکیک کنید

Domain Controllerها و سرویس‌های مدیریتی باید در مسیرهای کنترل‌شده قرار بگیرند. دسترسی مدیریتی از شبکه‌های کاربری عادی را تا حد امکان محدود کنید.

Monitoring و Audit

ثبت رخدادهای احراز هویت، تغییرات گروه‌های حساس و فعالیت‌های مدیریتی به تشخیص رفتار غیرعادی کمک می‌کند. لاگ بدون فرآیند بررسی، ارزش عملیاتی محدودی دارد.

Recovery را جدی بگیرید

امنیت بدون برنامه بازیابی کامل نیست. Backupهای محافظت‌شده، تست Restore و مستندسازی فرآیند بازیابی باید بخشی از طراحی باشند.

جمع‌بندی

Zero Trust یک محصول نیست؛ مجموعه‌ای از تصمیم‌های معماری و عملیاتی است. در Active Directory، شروع از حداقل دسترسی، جداسازی مدیریت، Audit و Monitoring مسیر مناسبی برای کاهش ریسک است.
