WINDOWS SERVER / SECURITY

سخت‌سازی Active Directory؛ چک‌لیست عملی

Active Directory قلب هویت در بسیاری از شبکه‌های ویندوزی است. امنیت آن باید از حساب‌های مدیریتی تا Group Policy و لاگ‌ها به شکل یک سیستم دیده شود.

حساب‌های مدیریتی را محدود کنید

حساب روزمره را از حساب مدیریتی جدا کنید، گروه‌های حساس را بازبینی کنید و دسترسی‌های قدیمی را حذف کنید.

Group Policy را هدفمند کنید

سیاست رمز عبور، قفل حساب، Windows Firewall، اجرای اسکریپت‌ها و تنظیمات امنیتی را مستند و قابل بازبینی نگه دارید.

سطح حمله را کم کنید

سرویس‌ها و پروتکل‌های غیرضروری را محدود کنید و دسترسی مدیریتی را از شبکه‌ها و سیستم‌های مورداعتماد انجام دهید.

لاگ و تشخیص

رویدادهای مهم احراز هویت و تغییرات مدیریتی را جمع‌آوری کنید و برای رفتارهای غیرعادی فرآیند بررسی داشته باشید.

پشتیبان‌گیری قابل بازیابی

فقط داشتن Backup کافی نیست؛ بازیابی را تست کنید و نسخه‌های مستقل در برابر خرابی و باج‌افزار داشته باشید.
