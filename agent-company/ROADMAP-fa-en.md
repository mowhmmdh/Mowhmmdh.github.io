# نقشه راه / Roadmap

## فاز ۱ — پایه امن / Safe foundation
- [x] ساخت شاخه مستقل؛ بدون تغییر در `main`
- [x] رابط نمایشی دوزبانه فارسی/انگلیسی با RTL/LTR
- [x] تعریف نقش‌های تخصصی و چرخه تأیید
- [x] سیاست امنیت، تست، ثبت رویداد و بازگشت
- [ ] انتقال این پروژه به مخزن خصوصی مستقل شرکت
- [ ] بررسی و تأیید دستی این پایه

## فاز ۲ — پنل محلی / Local control plane
- [ ] API محلی با FastAPI و پایگاه داده SQLite
- [ ] احراز هویت محلی و ثبت رویدادهای قابل حسابرسی
- [ ] صف وظایف با سقف تلاش، زمان اجرا و هزینه
- [ ] مدیریت وظایف: draft, queued, running, blocked, failed, review
- [ ] اجرای اولیه فقط در حالت مشاهده/پیش‌نویس

## فاز ۳ — ایجنت‌ها / Agents
- [ ] انتخاب مدل محلی یا API با تنظیم صریح
- [ ] ارکستریتور با وظایف محدود و خروجی ساختاریافته
- [ ] ایجنت‌های سئو، محتوا، مهندسی، امنیت/QA و تعمیر
- [ ] کنترل مستقل کیفیت و شواهد برای هر خروجی
- [ ] سقف هزینه، نرخ، هم‌زمانی و تلاش مجدد

## فاز ۴ — GitHub و تحویل / GitHub workflow
- [ ] ساخت شاخه جداگانه برای هر تغییر
- [ ] اجرای CI و تست‌های کیفیت
- [ ] PR به‌جای push مستقیم
- [ ] ادغام و انتشار فقط پس از تأیید انسانی
- [ ] برنامه بازگشت و گزارش بعد از انتشار

## فاز ۵ — گزارش‌دهی / Reporting
- [ ] گزارش هفتگی فارسی با خلاصه انگلیسی
- [ ] وظایف انجام‌شده، تغییرات و لینک شواهد
- [ ] تست‌های موفق/ناموفق، خطاها و ریسک‌های باز
- [ ] آمار واقعی بازدید فقط از منبع متصل و مجاز
- [ ] هزینه، مصرف مدل و پیشنهادهای هفته بعد

**وضعیت فعلی / Current status:** این شاخه شامل پایه مستندات و داشبورد نمایشی است. ایجنت‌ها هنوز به مدل یا ابزارهای اجرایی متصل نیستند.
