Active Directory hardening: a practical checklist

Active Directory is the identity core of many Windows networks. Its security should be treated as a system spanning privileged accounts, Group Policy, services and logging.

Limit privileged accounts

Separate daily and administrative accounts, review sensitive groups and remove obsolete access.

Use purposeful Group Policy

Document password policy, account lockout, Windows Firewall, script execution and security settings so they remain reviewable.

Reduce attack surface

Restrict unnecessary services and protocols and perform administration only from trusted systems and networks.

Logging and detection

Collect important authentication and administrative events and maintain a process for investigating anomalies.

Backups that can actually be restored

A backup is not enough. Test recovery and keep independent copies that remain useful during failures or ransomware incidents.
