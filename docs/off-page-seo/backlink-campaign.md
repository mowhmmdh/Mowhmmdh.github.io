# Off-Page SEO & Backlink Campaign

## Objective
Build legitimate topical authority for Mohammad Hossein Asgari Somarin and VinTech through editorial references, professional profiles, useful technical contributions, and genuine relationships.

## Rules
- No purchased ranking links.
- No bulk directory submissions.
- No automated backlink software.
- No private blog networks.
- No excessive reciprocal linking.
- No forum/comment spam.
- No fabricated clients, credentials, awards, case studies, or metrics.
- Prefer contextual links that help the reader.
- Use branded/natural anchors more often than exact-match commercial anchors.

## Priority targets

### Tier 1 — High relevance
1. StackHarden — pitch a practical Linux/server hardening guide.
2. Linuxize — monitor reopening of guest submissions; pitch Linux administration/security content when open.
3. DEV Community — publish an original companion article with a canonical link to the primary article when supported.
4. Hashnode — publish original technical companion content and reference the primary site article.
5. GitHub — maintain high-quality READMEs, project documentation, and profile links.
6. LinkedIn — distribute original technical insights and link to detailed articles where useful.

### Tier 2 — Technical community
7. Stack Overflow — answer relevant questions; link only when the site article directly solves the question.
8. Reddit — participate in relevant technical communities; link only when explicitly useful and permitted.
9. Relevant Linux/sysadmin/security communities — contribute tutorials, troubleshooting answers, and references.
10. Open-source project documentation — contribute fixes/docs where genuinely qualified.

### Tier 3 — Business/brand
11. Relevant technology directories with editorial value.
12. Local/regional IT business directories only when the listing is legitimate and accurate.
13. Vendor/community profiles where the user's real work or contribution qualifies.

## Anchor strategy
- Brand: Mowhmmdh / Mohammad Hossein Asgari Somarin
- Site: Professional website / technical knowledge base
- Topic: Linux server hardening / network hardening / GitLab CI/CD
- Natural URL anchors where appropriate
- Avoid repeated exact-match commercial anchors.

## Landing-page distribution
- Homepage: authority/identity links
- Blog articles: contextual technical links
- Projects/About: professional identity links
- VinTech: genuine service/business references

## Guest-post workflow
1. Research publication and editorial rules.
2. Pitch a topic that is not a copy of an existing article.
3. Only claim systems/versions that can actually be tested.
4. Produce original, useful technical content.
5. Request one natural author/site link where editorially allowed.
6. If paid placement is ever used for advertising, qualify the link with `rel="sponsored"` or `rel="nofollow"` as appropriate.
7. Track URL, date, target page, anchor, link attribute, and status.
